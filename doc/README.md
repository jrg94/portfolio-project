# Doc Folder

In general, the purpose of this folder is for storing documentation. For the
purposes of the portfolio project, this folder also holds all of the steps
to completing the project.

Historically, the subfolders were for completing the assignment in steps. You
are encouraged to still make use of these documents, but the following
information no longer applies and is only included for your reference:

> There are 6 of these assignments in this folder. The first 5 assignments are
> intended to be low-stakes assignments for getting feedback on your designs.
> The final assignment is where you will submit your completed component. The
> score breakdown for all 6 parts is as follows:
>
> | Assessment Type                      | Percentage of Grade |
> | ------------------------------------ | ------------------- |
> | Formative Assessments (5 @ 10% each) | 50%                 |
> | Summative Assessment                 | 50%                 |

Instead, you should complete the directions in the [one-shot](one-shot.md)
document. 100% of the scoring is based off a single submission.
